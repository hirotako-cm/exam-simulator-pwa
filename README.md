# exam-simulator-pwa

スマホで資格試験の模擬試験を解くための PWA。オフラインで動き、ビルド工程も外部依存もありません。

**問題データはこのリポジトリに含まれていません。** アプリは空の状態で起動し、自分で用意した問題 JSON を端末にインポートして使います。試験問題を公開せずにアプリだけを配信できるようにするための設計です。

## 特徴

- **本番シミュレーターに特化** — 解答中は正誤も分野も表示せず、提出後にまとめて採点・解説を開示します
- **時間計測** — 出題数に応じて制限時間を比例計算（既定は 53問=120分）。設問ごとの所要時間も記録します
- **中断・再開** — 解答・取り消し線・フラグを逐次保存し、アプリを閉じても続きから再開できます。残り時間は実時間で進みます（本番同様）
- **選択肢の取り消し線** — 各選択肢の ✕ で除外の目印を付けられます（付けても選択は可能）
- **あとで見直すフラグ** — 提出前の解答一覧を「見直しのみ」「未解答のみ」で絞り込めます
- **複数選択式に対応** — multiple-choice と multiple-response（「2つ選べ」）の両方。選択肢は A〜D 固定ではなく 5択以上も扱えます
- **本番同様の言語ポリシー** — 解答画面は英語のみ、提出後の復習画面は英日併記（言語切替 UI はありません）。`translate="no"` によりブラウザの自動翻訳も起動しません
- **左右分割レイアウト** — `context`（シナリオ前段）を持つ問題は、PC 幅で左＝前段／右＝質問＋選択肢の 2 ペイン表示（スマホは縦積み）
- **問題のブラッシュアップ** — 解きながら各問に指摘メモを付け、問題ごとまとめてエクスポート。手元で修正して再インポートしても、受験履歴とメモは問題 ID で維持されます
- **複数の問題セット** を名前付きで保持し、切り替えられます。不要になったセットは削除可能（履歴・メモを残して削除すれば、再インポート時に引き継がれます）
- オフライン動作、ダークモード対応

## 使い方

### ホスティングに置く（推奨）

静的ファイルをそのまま配信するだけです。GitHub Pages なら Settings → Pages でブランチを指定すれば動きます。

スマホで開いて「ホーム画面に追加」すると、アイコンから standalone 起動し、Service Worker がアプリ本体をキャッシュするので以降は完全にオフラインで使えます。

### 端末に直接置く

`file://` でも動きます（Service Worker の登録だけスキップされます）。ファイル一式を端末に送り、`index.html` をブラウザで開いてください。

ただし iOS Safari の `file://` はオリジンが `null` になり保存領域が使えない場合があります。その場合は画面上部に警告バナーが出ます。安定して使うならホスティング経由を推奨します。

### 問題をインポートする

ホーム画面の「問題セットをインポート」から、ファイル選択またはテキスト貼り付けで JSON を読み込みます。

## 問題 JSON のスキーマ

```jsonc
{
  "schemaVersion": 2,
  "set": {
    "id": "my-exam",           // 履歴・メモの紐付けキー。変更しない
    "name": "私の模擬試験",
    "examCode": "XXX-F",
    "officialCount": 53,       // 本番の出題数（「本番相当」プリセットになる）
    "officialMinutes": 120,    // 本番の制限時間（制限時間の比例計算の基準）
    "passRate": 0.7
  },
  "questions": [
    {
      "id": 0,                 // セット内で一意・不変。履歴と紐づく
      "type": "single",        // "single" | "multi"
      "selectCount": 1,        // multi のとき選ぶ数
      "question": "問題文",
      "options": { "A": "…", "B": "…", "C": "…", "D": "…" },
      "correct": "C",          // single: "C" / multi: ["A","C"]
      "explanation": "解説",
      "study_area": "分野名",   // 提出後の復習画面で表示される
      "scenario": "Scenario: …",        // 任意。左ペインの見出し
      "context": ["前段の段落1", "段落2"], // 任意。左ペインに表示するシナリオ前段
      "context_ja": ["和訳1", "和訳2"],   // 任意。復習画面の英日併記用
      "question_ja": "和訳（任意）",
      "options_ja": { "A": "…", "B": "…", "C": "…", "D": "…" },
      "explanation_ja": "解説の和訳（任意）"
    }
  ],
  "notes": {}                  // アプリが書き出す指摘メモ
}
```

- `options` のキーは A〜D 固定ではありません。`E` 以降も扱えます
- `_ja` 系のフィールドは任意です。無い場合は復習画面でも英語のみ表示されます
- 単純な配列（`[{question, options, correct, explanation, id}, …]`）を渡した場合も v2 として読み込まれ、`type` と `selectCount` が補完されます

採点は `single` はキーの一致、`multi` は選択集合の完全一致（部分点なし）です。

## 構成

ビルドしません。ファイルをそのまま配信します。

| ファイル | 役割 |
|---|---|
| `index.html` | 全画面のマークアップ |
| `app.js` | ロジック（バニラ JS、依存なし） |
| `styles.css` | スタイル |
| `sw.js` | Service Worker（アプリ本体のオフラインキャッシュ） |
| `manifest.json` | PWA マニフェスト |
| `icons/` | アイコン（192 / 512） |
| `SPEC.md` | 仕様書 |
| `PLAN.md` | 最初の要求メモ |

## データの保存場所

すべて端末内で完結します。サーバーに何も送りません。

| 置き場所 | キー | 内容 |
|---|---|---|
| IndexedDB | `study-app` / `sets` | 問題セット本体 |
| localStorage | `sa-notes-v1` | 指摘メモ |
| localStorage | `sa-history-v1` | 受験履歴 |
| localStorage | `sa-session-v1` | 進行中のセッション |
| localStorage | `sa-prefs-v1` | シャッフルなどの設定 |

IndexedDB が使えない環境では localStorage、それも使えなければメモリのみ（警告バナーを表示）と段階的にフォールバックします。

## キーボードショートカット

PC でも使えます。

解答画面:

| キー | 動作 |
|---|---|
| 選択肢のキー（`A`、`B`、…） | その選択肢を選択／解除 |
| `←` / `→` | 前の問題 / 次の問題 |
| `F` | あとで見直すフラグ |
| `M` | 指摘メモ |

復習画面（提出後）:

| キー | 動作 |
|---|---|
| `←` / `→` | 前 / 次 |
| `C` | 解説用にクリップボードへコピー |
| `M` | 指摘メモ |

解答一覧画面では `Esc` で解答画面に戻ります。

選択肢のキー判定が先に来るため、6択以上で `F` / `M` が選択肢キーになっている場合は、選択肢の選択として扱われます。
